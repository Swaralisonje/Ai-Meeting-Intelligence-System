**🤖 AI Meeting Assistant**

An AI-powered Meeting Assistant that automatically joins online meetings, captures conversations, generates structured summaries, and extracts actionable insights.
This project is designed to improve productivity by eliminating manual note-taking and helping teams focus on discussions.

------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

**🚀 Features**

🔗 Automatically joins Google Meet meetings using a meeting link

🎙️ Captures meeting audio in real time

🧠 Converts speech to text using AI-based transcription

📝 Generates concise meeting summaries

✅ Extracts action items, decisions, and key points

📄 Stores meeting transcripts and summaries for future reference

🌐 Backend API for seamless integration with other applications

------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

**🧪 How It Works**

User provides a meeting link

Bot automatically joins the meeting

Audio is captured and transcribed

AI analyzes the transcript

Summary, action items, and insights are generated
